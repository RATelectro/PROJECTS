Key Modifier combo Layer key Transparent Disabled Row 1 is the physical top row. Click a key to edit it. A transparent key falls through to the layer shown in the corner.
“Apply” writes the changed layers to the keyboard and saves them to flash. A full backup of the previous keymap is created automatically first (see Backups tab).

LED settings

LED settings are saved to the keyboard automatically (about 2 s after the last change) and restored at boot, so they survive power loss. Use “Save LED settings now” to persist immediately without waiting.

Storage

RECALL reloads the saved keymap from flash, discarding unsaved changes. RESET restores compiled defaults in RAM only — use “Save all” afterwards to persist.

Presets

Presets are stored inside this app (browser profile) and can be exported as JSON files. Applying a preset edits the keymap locally — use “Apply to keyboard” on the Keymap tab to flash it (a backup is created automatically).

Backups

Before every flash, the current keymap is dumped from the keyboard and stored here. Up to 100 backups are kept; the oldest are removed automatically. Restore writes a backup straight back to the keyboard (the current state is backed up first).
